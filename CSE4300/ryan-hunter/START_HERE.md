# Start here

This folder contains the completed Linux Mini Task Manager and supporting materials for Ryan Nguyen and Hunter Maxwell.

1. Open `README.md` for build instructions and commands. On Linux, run `make`, then `./minitask`.
2. Run `make test` on the machine you will use to present. The included sandbox evidence records 54 C checks, 21 CLI/terminal checks, and a separate 180-refresh run that passed.
3. Read `docs/Mini_Task_Manager_Report.pdf` for the design and `docs/EXPLANATION_GUIDE.md` for likely questions. The recorded demo is in `docs/Recorded_Terminal_Demo.pdf` and `results/`.
4. Open the editable slides using `docs/PRESENTATION.md`. Download/export the deck as `.pptx` into `docs/` before uploading to GitHub. `docs/SPEAKER_NOTES.md` proposes about 6–7 minutes each: Hunter on slides 1–6, Ryan on slides 7–12.
5. Review `docs/PROVENANCE.md` and describe each member's actual contributions and any assistance accurately.
6. Follow `docs/DEMO_AND_SUBMISSION.md` to practice the demo and submit the extracted project folder yourself.

The source is ready to build. Compiled binaries are excluded so the package can be built on your own Linux machine. No GitHub submission has been made by the assistant.
